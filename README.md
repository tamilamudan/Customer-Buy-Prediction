Introduction
This project uses Logistic Regression to predict whether a customer will purchase a product based on their age and estimated salary. It demonstrates an end-to-end supervised learning workflow using Scikit-learn and Pandas. The model is trained on a digital ad dataset and includes real-time prediction functionality based on user input.

✅ Key Features:
Data loading and preprocessing using Pandas

Feature extraction with NumPy

Dataset splitting using train_test_split

Feature scaling with StandardScaler

Logistic Regression model training with Scikit-learn

Prediction and performance evaluation using accuracy_score

Real-time prediction via user input

Side-by-side comparison of predicted vs actual values
